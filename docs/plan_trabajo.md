# Plan de trabajo para la construcción del módulo Frontend - Blog Walkers

**Tecnología:** React JS  
**Objetivo:** Desarrollar el módulo de interfaz web para visualización de contenido sobre senderismo.

## Fases del desarrollo
1. **Análisis y diseño:** revisión de requerimientos, casos de uso, y estructura del contenido.
2. **Prototipado:** diseño visual de las pantallas principales.
3. **Codificación:** desarrollo en React con componentes funcionales y hooks.
4. **Pruebas:** validación de interfaz y comportamiento del estado.
5. **Versionamiento:** gestión de versiones con Git y GitHub.
6. **Entrega final:** documentación y despliegue.

## Recursos utilizados
- Visual Studio Code  
- Node.js + npm  
- React JS  
- Git / GitHub
