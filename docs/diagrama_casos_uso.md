# Diagrama de Casos de Uso - Blog Walkers

**Actor principal:** Visitante / Usuario del blog

## Casos de uso principales
- **CU01 - Visualizar artículos**
  - Actor: Visitante
  - Descripción: El usuario accede al sitio y lee artículos informativos sobre senderismo.
- **CU02 - Ver galería de imágenes**
  - Actor: Visitante
  - Descripción: El usuario observa fotografías inspiradoras relacionadas con rutas y experiencias.
- **CU03 - Mostrar mensaje motivacional**
  - Actor: Usuario
  - Descripción: Al hacer clic en el botón, el sistema muestra un mensaje motivacional.
- **CU04 - Contactar al administrador**
  - Actor: Usuario
  - Descripción: El usuario puede enviar un correo desde el enlace del pie de página.

## Relación actores - casos
| Actor | Casos de Uso |
|--------|---------------|
| Visitante | CU01, CU02 |
| Usuario | CU03, CU04 |
